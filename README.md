# Stayora — Local Stay Finder

A responsive, one-page accommodation discovery website concept for Tunasan, Muntinlupa and nearby Alabang. Built with plain HTML, CSS, and JavaScript — no build step or framework required.

## Preview locally

1. Download or clone this repository.
2. Open `index.html` in a browser.
3. That's it — no package installation or build command needed.

## Publish with GitHub Pages

1. Create a GitHub repository and upload the contents of this ZIP.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site.

## Customize before publishing

- Update the brand name and copy in `index.html`.
- Replace the illustrative nightly rates with verified, current rates.
- Replace demo contact email `hello@stayora.example` with your real email.
- Confirm property names, addresses, contact details, ratings, availability, and booking links.
- Update the discount copy to reflect real promotions. No specific discount is promised by this demo.
- The hero and property-card artwork is CSS illustration, so no local image assets are required.

## Important note about sample listings

This is a demonstration directory, not an official booking partner or live inventory feed. The rates shown are rounded illustrative starting estimates based on publicly listed search results around Tunasan/Muntinlupa and may be outdated or unavailable. Confirm directly with each property or booking platform. Rating labels are sourced from third-party listings and can change. The contact email is intentionally a placeholder.

## Files

- `index.html` — page structure and sample listings
- `styles.css` — responsive layout, cream/white/orange theme, CSS artwork
- `script.js` — working area and budget filters, mobile navigation, and dynamic year
